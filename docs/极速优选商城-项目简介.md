极速优选商城——基于 Spring Cloud 的 B2C 微服务秒杀商城

技术栈：Spring Cloud、Nacos、Spring Cloud Gateway、SkyWalking、

OpenFeign、Sentinel、MyBatis、RabbitMQ、MySQL、Redis、JWT、Vue3

项目简介：面向 B2C 场景的微服务商城系统，包含 PC 商城（会员端）与后台管理（管

理端）两类入口，覆盖商品、购物车、订单支付、秒杀抢购、RBAC 权限管理等核心

业务，支持服务独立部署与横向扩展，秒杀支撑 5000 级并发。 项目核心功能：

微服务架构与治理：Spring Cloud Alibaba 微服务拆分与网关，Nacos 注册

配置，OpenFeign 调用，Sentinel 限流熔断，SkyWalking 链路追踪；

登录鉴权：JWT 双端登录签发令牌，网关校验并注入身份，BCrypt 加密，

RBAC 用户组-角色-权限-资源鉴权，越权访问拒绝，菜单按权限动态渲染；

秒杀支付：采用雪花算法生成订单号，模拟支付，通过 RabbitMQ 延时消息

关闭超时订单并释放库存；秒杀采用 Redis+Lua 原子扣减防超卖、异步削峰。
