## 1 项目当前完成度概览（对照基线，V1.1 更新）

- **业务微服务**：brand(20001) / category(20002) / good(20003) / member(20004) / member-address(20005) / region(20006) / cart(20007) / order(20008) / user(20009) / rbac(20010) / seckill(20011) / **upload(20012)**，网关(8888)；
- **数据库**：22 张表 DDL（flashchoice-mart.sql）+ 全量测试数据（测试数据.sql）+ t_refresh_token.sql；
- **认证**：JWT 双 Token（签发/一次性刷新轮换/登出吊销/Redis 黑名单/网关统一校验/身份头注入与防伪）；
- **防刷**：登录/注册图形验证码（EasyCaptcha + Redis 一次性校验，2 分钟有效；member/user 各提供 `/captcha` 端点，网关白名单放行）；**网关限流**（认证入口 20 次/分/IP、其余 300 次/分/IP，超限 429）；
- **网关防护**：JWT 认证 + **RBAC 授权过滤**（admin 写操作调 `/api/rbac/check`，60 秒本地缓存，未授权 403）+ **内部接口拦截**（库存扣减/回补、超时关单、RBAC 判定等外部访问 403）；
- **下单链路**：收货地址与商品明细快照、库存条件扣减（qty>=count）与回补、购物车清除（Feign 跨服务）；订单号雪花 ID；**RabbitMQ 延时关单（TTL + 死信队列）+ 定时扫描兜底**；
- **订单**：状态机、模拟支付、模拟退款、发货、确认收货、超时关单；后台/会员身份判定按 `X-Audience` 收口；
- **RBAC**：基础数据 CRUD、覆盖式授权分配、`/api/rbac/check` 权限判定、`/api/menus/mine` 动态菜单、`/api/rbac/mine/resources` 按钮资源标识；
- **文件上传**：upload 服务（`POST /upload/image` 上传、`GET /upload/files/**` 公开读取；白名单 + 5MB + UUID 防覆盖 + 防路径穿越）；
- **秒杀**：活动/活动商品 CRUD、抢购、结果查询、订单与库存回补；
- **前端**：`FlashChoiceMart-frontend/mall-web`（Vue3 + Element Plus + Pinia + Axios，商城 + 后台管理页面；401 自动刷新队列、开发代理 `/api`、`/upload` → 网关）；
- **配置**：业务微服务已接入 Nacos 配置中心（`import nacos:common.yaml`）。

#### P0-3 网关 RBAC 授权过滤器 ✅ 已完成

**设计依据**：详细设计 4.3、6.1（后台写接口由网关调用 rbac-api 权限判定，未授权 403）、5.8。

**完成情况**（`RbacAuthGlobalFilter`，order=-90）：
1. 仅对「admin 令牌 + 写操作（POST/PUT/DELETE/PATCH）」调用 rbac-api `/api/rbac/check`；游客/会员请求不做判定（数据归属由各服务自校验）；
2. 使用 `WebClient`（非阻塞）调用，超时 2s；判定结果 Caffeine 本地缓存 60 秒（权限调整后最多 60 秒生效）；
3. 未授权返回 403 JsonResp；rbac-api 不可用时降级放行（仅告警），公开 GET/白名单不受影响；
4. 依赖的 P0-4 订单身份判定已完成（后台订单接口在授权放行后可正常使用）。

#### P0-4 订单模块后台/会员身份判定 ✅ 已完成

**设计依据**：详细设计 4.5（后台可发货/取消/退款）、8.2（模拟支付防伪造、数据归属校验）、6.1（身份头约定）。

**完成情况**（统一按 `X-Audience` 区分，`OrderApi` 身份判定辅助方法）：
- `member`：订单分页/详情/退款/取消强制绑定本人账号并做归属校验；
- `admin`：跳过归属校验、不做会员过滤，后台订单查询与取消正常可用；
- 后台专属操作（`ship`、`refund/confirm`、批量删除）要求 `X-Audience=admin`，会员令牌调用返回 403；
- 会员专属操作（`pay`、`pay/confirm`、`confirm`、提交订单）后台令牌直接 403；退款/取消归属校验已补全（越权修复）。

#### P1-2 订单超时关单 RabbitMQ 延时消息 ✅ 已完成

**设计依据**：5.5.2、6.2（30 分钟延时消息 + 定时兜底）、8.3（消费失败重试 + 死信队列）。

**完成情况**：
1. `RabbitMqConfig`：TTL + 死信队列实现 30 分钟延时投递（DELAY_EXCHANGE / CLOSE_QUEUE）；
2. 下单成功后发送延时消息（orderNo）；`OrderCloseMessageListener` 消费并调用 `closeTimeoutOrder`（幂等：按订单状态判断）；
3. 消费失败进入死信队列兜底；每分钟定时扫描保留为最终兜底；
4. order 服务 `application.yaml` 已补充 RabbitMQ 连接配置（本地未部署时下单/定时关单不受影响）。

#### P1-3 网关限流与防刷 ✅ 已完成

**设计依据**：5.8（令牌桶限流）、8.2（登录失败限流、429 响应）。

**完成情况**（`RateLimitGlobalFilter`，Redis 计数窗口，order=-105）：
1. 认证入口（登录/注册/验证码/刷新，即白名单路径）每 IP 每分钟 20 次；其余接口每 IP 每分钟 300 次；超限返回 429 JsonResp；
2. Redis 不可用时降级放行（仅告警）；客户端 IP 优先取 `X-Forwarded-For`（Nginx 反代场景）；
3. 秒杀抢购使用 Redis Lua 原子库存与用户限购；网关通用限流仍生效，专用压测与参数调优待目标环境完成。

#### P1-4 服务间接口越权收口 ✅ 已完成

**完成情况**（`InternalApiGuardFilter`，网关最外层 order=-110）：
- 内部接口清单化配置（`fcm.gateway.internal-paths`）：`PUT /api/goods/stock/deduct`、`PUT /api/goods/stock/restore`、`PUT /api/orders/close-timeout/**`、`POST /api/rbac/check`、`DELETE /api/rbac/users/*/groups`；
- 外部请求命中即返回 403「内部接口禁止外部访问」，仅供服务间 Feign 直连调用（配合各服务业务层校验构成双层防护）。
